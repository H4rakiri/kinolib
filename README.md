# Кинолента

Персональная библиотека фильмов, сериалов и аниме. Русские названия, постеры,
хронометраж, сезоны/серии; просмотр топов по коллекциям и жанрам, поиск и личные
статусы «Хочу посмотреть / Смотрю / Посмотрел». Чистая статика — хостится
бесплатно на GitHub Pages.

## Как это устроено

- **Каталог** — файл `public/data/catalog.json`, который собирается заранее
  скриптом и коммитится в репозиторий. Сайт читает готовый JSON: без API-ключей
  в браузере, без лимитов, работает быстро. Постеры тянутся по ссылкам и
  кэшируются браузером — хранилище репозитория ими не забивается.
- **Личная библиотека** (статусы + подборки) — хранится в браузере (`localStorage`)
  и синхронизируется между устройствами через `library.json` в приватном
  репозитории GitHub. Есть также экспорт/импорт JSON.

## Синхронизация библиотеки между устройствами

1. Создан приватный репозиторий данных (по умолчанию `H4rakiri/kinolib-data`)
   с файлом `library.json`.
2. Создай personal access token с доступом на запись содержимого этого репозитория:
   - **classic**: scope `repo`;
   - **fine-grained**: только этот репозиторий, разрешение *Contents: Read and write*.
3. На вкладке **Библиотека → Синхронизация** впиши репозиторий и токен, нажми
   «Сохранить и подключить». Токен хранится только в этом браузере (`localStorage`).
4. Дальше всё автоматически: при открытии подтягивается облачная версия, при
   изменениях — сохраняется обратно (каждое сохранение = коммит, вся история в git).
   При расхождении побеждает более свежая по времени версия.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка каталога

Нужен бесплатный ключ [kinopoiskapiunofficial.tech](https://kinopoiskapiunofficial.tech/)
(`KP_TOKEN`).

```bash
KP_TOKEN=xxxx npm run fetch-data
```

Скрипт перезапишет `public/data/catalog.json` (коллекции: Топ Кинопоиска,
Популярное, Сериалы, Топ аниме; жанры и хронометраж). Настройки коллекций и
глубины (сколько страниц тянуть) — в начале `scripts/fetch-data.mjs`. Учитывай
дневной лимит бесплатного тарифа (~500 запросов/сутки).

## Деплой на GitHub Pages

1. Создай публичный репозиторий и запушь код в ветку `main`.
2. В `Settings → Pages` выбери источник **GitHub Actions**.
3. В `Settings → Secrets and variables → Actions` добавь секреты `KP_TOKEN`
   (и `TMDB_TOKEN`, если нужен).
4. Пуш в `main` собирает и публикует сайт (`.github/workflows/deploy.yml`).
5. Каталог обновляется автоматически раз в неделю
   (`.github/workflows/fetch-data.yml`) — или вручную через вкладку **Actions**.

Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.
`base: './'` в `vite.config.js` уже настроен на работу в подкаталоге.

## Структура

```
public/data/catalog.json   — запечённый каталог (демо-данные, заменяются скриптом)
scripts/fetch-data.mjs     — сбор каталога из Кинопоиска (+TMDB)
src/lib/catalog.js         — загрузка и выборки (поиск, жанры, коллекции)
src/lib/library.js         — личная библиотека (статусы, экспорт/импорт)
src/lib/format.js          — хронометраж, склонения, статусы
src/components/            — карточка, сетка, детали
```
